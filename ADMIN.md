# Admin havolalari va guruhni o‘chirish

Admin havolasini Sozlamalar → Adminlar uchun taklif havolalari bo‘limida yaratish mumkin.
Havola ko‘p martalik va uni yaratgan admin bekor qilguncha ishlaydi.
To‘liq havola yaratilganida bir marta ko‘rsatiladi; nusxalab saqlang.
Havolani olgan odam yangi login va parol bilan alohida admin (ustoz) hisobi ochadi.
Mavjud hisob avtomatik o‘zgartirilmaydi. Yangi admin o‘z guruhlarini yaratadi;
boshqa ustozlarning yopiq guruhlariga avtomatik kirish berilmaydi.
Havola maxfiy: uni olgan odam admin hisobi yarata oladi.

Guruh admini guruh sahifasidagi «Guruhni o‘chirish» tugmasini bosib,
guruh nomini aynan yozib tasdiqlaydi. Shu guruhning mahsulotlari, a’zoliklari,
takliflari, jadvallari, lokatsiyalari, so‘rovlari va narx tarixi tozalanadi.
Foydalanuvchi hisoblari, parollar, sessiyalar va boshqa guruhlar saqlanadi.
O‘chirilgan guruhning ID si qayta ishlatilmaydi; uni arxivdan qaytarish amali bilan tiklab bo‘lmaydi.
Qaytarish zarur bo‘lsa server zaxirasidan alohida tiklash kerak.

v4 migratsiyasi mavjud hisob va tarixni o‘zgartirmasdan admin_invites jadvali va
guruh o‘chirilgani haqidagi ustunlarni qo‘shadi. Ishga tushirishdan oldin zaxira oling.

admin havolasining ko‘p martalik ishlashi, bekor qilinishi va ruxsat cheklovlari bajarildi.
